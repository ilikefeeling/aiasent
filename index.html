📌 과제 공식 정의

"'AI Token MVNO 플랫폼' On-Device 경량 SLM과 MCP 기반 개인 지식자산화, 그리고 제휴 수수료 정산 엔진을 결합하여 개인의 AI 토큰 비용 최소화 실현"

🔧 4-Layer 핵심 아키텍처

  • Layer 01 — On-Device SLM 추론 엔진: 4-bit 양자화(AWQ), WebGPU/NPU 가속, RAM 1.8GB 미만 동작, 150ms 이내 로컬 응답. 오프라인 동작 보장.
  • Layer 02 — MCP 지식 자산화 엔진: Anthropic 개방 표준 MCP(Model Context Protocol) 기반. 로컬 파일/노션/슬랙/브라우저 데이터를 비동기 수집·청킹·임베딩하여 Zero-ETL 지식 그래프 자동 구축.
  • Layer 03 — 로컬 프라이빗 Vector DB: SQLite-VSS 온디바이스 스토리지. Zero-Knowledge 암호화. BM25 + 밀집 벡터 하이브리드 검색으로 초개인화 RAG 실현.
  • Layer 04 — Intelligent Hybrid Router: 사용자 질의의 복잡도와 프라이버시 요구도를 실시간 스코어링. 80% 이하는 로컬 SLM(₩0), 초과 시에만 클라우드 LLM 선택적 분기.

📊 해결하고자 하는 3대 문제

  • 토큰 인플레이션: 생성형 AI 사용량 비례 종량제 비용 폭증. 국내 AI 파워유저 월 지출 ₩70,000~350,000+. 소상공인과 헤비유저의 AI 활용 위축.
  • 개인 지식 종속: 사용자의 보고서, 대화, 메모가 클라우드 LLM 학습 원료로만 소모. 매 세션마다 동일 맥락 반복 입력(일평균 47분 낭비). 사내 기밀 유출 불안 상존.
  • 제휴 마케팅 한계: 서드파티 쿠키 종말로 기존 디스플레이 배너 CTR 0.1% 미만, CVR 0.12% 이하로 급락. 진성 고객 접점 확보 비용 폭증.

💰 AI Token MVNO 비용 상쇄 메커니즘

알뜰폰(MVNO)이 통신망을 효율화하듯, Aiasent는 로컬 AI와 제휴 수수료를 결합해 지속 가능한 흑자 비즈니스를 완성합니다.

  • Unit Economics: 유저 1인당 월 토큰 비용 약 -₩1,500 / 제휴 수수료 수익 +₩4,800 / 순 공헌이익 +₩3,300
  • 수익 구조 (Proactive): AI가 유저의 익명화된 데이터를 바탕으로 최적의 소비 타이밍을 선제적으로 추천하고, 전환 시 3~15% 수수료를 수취합니다.
  • 적자 리스크 제로 (No Credit): 유저의 제휴 수익 잔고가 0원이면 클라우드 AI 연결을 차단하고 로컬 SLM으로만 답변하여 회사의 비용 손실을 원천 봉쇄합니다.
